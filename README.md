# ALFA KADE — آلفا کده

نسخه توسعه‌یافته پروژه مقایسه قیمت با ظاهر مشکی/طلایی.

## امکانات اضافه‌شده
- نام سازنده در نوار بالای سایت: «سازنده: نیماحجتی»
- بخش تنظیمات با «پشتیبانی» و «پیشنهادات» و ایمیل `alphakade11@gmail.com`
- ثبت محصول با دو مسیر: ۱) اتصال به سایت ۲) ثبت محصول بدون سایت
- در حالت بدون سایت، آدرس سایت درخواست نمی‌شود.
- برای محصول جدید، آپلود تصویر انجام می‌شود؛ برای محصول موجود، تصویر دوباره لازم نیست و فقط پیشنهاد قیمت/فروشنده اضافه می‌شود.
- اطلاعات ثبت‌کننده: نام، شماره تماس، کد ملی و تاریخ تولد
- سقف قطعی قیمت هر محصول: ۵۰۰,۰۰۰,۰۰۰ تومان (در دیتابیس هم enforce می‌شود)
- سقف محصولات: ۱۰,۰۰۰,۰۰۰
- سقف فروشنده برای هر محصول: ۱,۰۰۰
- پنل رئیس پروژه برای تغییر هزینه ثبت، هزینه تمدید، مدت تمدید، سقف محصولات، سقف فروشندگان و ایمیل‌ها بدون کدنویسی
- هزینه ثبت کالای جدید به‌صورت پیش‌فرض رایگان است.
- ورود پیامکی عمداً در این نسخه متصل نشده و فقط جای آن در پروژه آماده است.

## راه‌اندازی
1. پروژه را داخل GitHub قرار بده.
2. یک پروژه Supabase بساز و متغیرهای `.env.local` را طبق `.env.example` تنظیم کن.
3. فایل `supabase/schema.sql` را در SQL Editor اجرا کن.
4. برای فعال شدن پنل رئیس پروژه، بعد از اولین ورود، role کاربر موردنظر را در جدول `profiles` به `admin` تغییر بده.
5. برای ورود با شماره و کد پیامکی، بعداً Phone Auth و سرویس پیامک را وصل کن.
6. سپس `npm install` و `npm run build`/`npm run start` را اجرا کن.

> درگاه پرداخت واقعی به کلید و سرویس پرداخت نیاز دارد. پنل هزینه را آماده کرده‌ایم، اما بدون مشخصات درگاه نمی‌توان تراکنش واقعی را وانمود کرد.
